# Начните здесь — 0.13.0

Этот комплект продолжает исходный Git-снимок 0.10.0; история этого продолжения сохранена.

Реально выполнены компиляция Roslyn/C#13 и тесты на альтернативном .NET 11 preview-host.
Это не штатная .NET 9/Windows-сборка и не проверенная русификация игры.

## Сборка для Windows

Откройте терминал в папке project и выполните:

```powershell
py -3 -m pip install -r validation/requirements.txt
.\build.cmd --rids win-x64
```

Нужны Python 3.11+ и .NET 9 SDK. Не отключайте проверочные этапы при ошибке.
Только после успешного завершения программы появляются в
`artifacts/releases/0.13.0/win-x64/` и ZIP рядом с этой папкой.
Пакеты Linux+Windows за один запуск: `build.cmd`.

Читайте `docs/USAGE_RU.md`, затем `docs/CUSTOMER_DEMO_RU.md`.
Показывайте синтетические примеры как синтетику, а не как работающую игру.
