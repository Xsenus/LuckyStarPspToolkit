# Начните здесь — 0.16.0, комплект ВЛАДЕЛЬЦА

Это весь проект, а не клиентский дистрибутив. Не передавайте этот архив, Git bundle и инструменты выдачи ключей заказчику.

1. Прочитайте `docs/LICENSE_OWNER_RU.md`: сборка owner tools, создание издателя на вашем VPS, HTTPS, ключи доступа.
2. Создайте собственного издателя. Встройте только его `client-trust.json` в клиентский EXE через `--license-trust`.
3. Отправляйте клиенту только проверенный клиентский ZIP, затем отдельно txt с ключом.
4. Для клиента: `docs/LICENSE_CUSTOMER_RU.md`. Для модели защиты/ограничений: `docs/LICENSE_SECURITY_RU.md`.
5. Результаты выполненных проверок: `docs/TEST_REPORT_RU.md` и `reports/` полного комплекта.

Без встроенного издателя рабочие команды возвращают LICENSE_NOT_CONFIGURED. Без активации — LICENSE_REQUIRED.
Бессрочный доступ также требует сервер. Полная локальная C# программа не является невзламываемым DRM.

Штатная сборка (нужны .NET 9 SDK и Python 3.11+):

```powershell
py -3 -m pip install -r validation/requirements.txt
py -3 scripts/build_license_owner.py --rids linux-x64,win-x64
.\build.cmd --rids win-x64 --license-trust C:\LspOwner\client-trust.json
```

Реальные исходные данные игры и шрифты не включены. Сборки диагностического runtime также не включены.
Git bundle сохраняет историю с чистого снимка 0.10.0. Перед публичным размещением проверьте THIRD_PARTY_NOTICES.md;
публичные исходники позволяют убрать клиентскую проверку лицензии.
