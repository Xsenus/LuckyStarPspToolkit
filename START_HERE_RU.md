# Начните с этого файла

Версия 0.10.0 — исходный engineering preview, НЕ готовый подтверждённый русификатор. В этой среде C# не скомпилирован: .NET SDK отсутствовал.

1. Прочитайте docs/USAGE_RU.md.
2. Установите .NET 9 SDK и Python 3.11+, зависимости validation/requirements.txt.
3. Из корня проекта запустите build.cmd --rids win-x64. Ожидайте фактический нулевой код завершения.
4. После успешной сборки запускайте artifacts/releases/0.10.0/win-x64/lsptool.exe из терминала.
5. Для показа используйте docs/CUSTOMER_DEMO_RU.md.
6. Для GitHub — docs/GITHUB_PUBLISH_RU.md; до публичного раскрытия проверьте THIRD_PARTY_NOTICES.md.

Файлы игр, шрифтов и готовые бинарники не включены. Синтетические fixtures генерируются сборочным драйвером. Точные результаты выполненных здесь проверок: docs/TEST_REPORT_RU.md и reports/ в полном архиве.
