# Synthetic examples

All files in this directory are metadata-only examples. They contain no game, firmware, commercial font, or translation content.

- `iso-patch-manifest.example.json` — strict manifest for rebuilding a new ISO copy.
- `translation-entry.example.json` — one editable translation record.
- `glyph-map.example.txt` — minimal illustrative glyph map, not a complete game map.

Replace placeholder hashes and paths with values produced from your own files. Never remove hash preconditions merely to make a patch apply.
