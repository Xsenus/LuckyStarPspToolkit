vectors; UTF cell/payload budgets; malformed-header regressions; corrected font demo exit

C# compilation/native publication and real game acceptance not verified in the preparation environment.

- Добавлен `scripts/package_release.py` для воспроизводимого source/runner/validation/Git/full-handoff комплекта с проверкой CRC, путей, manifest и SHA-256.

## 0.8.0

- Добавлен точный профиль `rgo-uljm05752-russian-vwf-v1` для подтверждённого EBOOT `ULJM05752`.
- Профиль содержит 133 проверяемые 32-битные MIPS-замены в пяти группах: VWF core, message, speaker, choice и name layout.
- Добавлены команды `eboot-vwf-groups`, `eboot-vwf-inspect`, `eboot-vwf-apply` и объединяющий alias `eboot-build`.
- Поддерживается идемпотентное применение, завершение частичного профиля и распознавание точного полного результата по SHA-256.
- Каноническая проверка происхождения допускает только известные VWF-слова, внутренне согласованную таблицу сценариев и точно рассчитанный script heap.
- Добавлено автоматическое увеличение RGO script heap сверх исходных `0x236000` байт.
- Размер heap кодируется проверенной парой MIPS `lui a0` / `addiu a0,a0` с корректным знаковым `%hi/%lo` и обратной проверкой.
- Исправлено объединение VWF с `eboot-size-plan`: теперь в итог переносятся таблица размеров и обе heap-инструкции, а не только таблица.
- Добавлена побайтовая проверка всех изменений size-plan и запрет пересечения динамических областей с 133 VWF-словами.
- `apply-eboot-plan` после применения повторно проверяет каноническую линию происхождения, таблицу и heap.
- Общий `verify-eboot` распознаёт исходный, полный VWF и известный partial/size-adjusted варианты.
- Полностью применённый VWF с согласованными size table/heap теперь проходит `verify-eboot` как готовый результат; частичный профиль возвращает отдельный статус incomplete.
- Добавлены декларативный JSON-профиль, строгая JSON Schema и синхронизация профиля с C#-массивом в release gate.
- Добавлен независимый Python-oracle на реальном EBOOT заказчика: полный hash, идемпотентность, partial completion, таблица, heap 1200×2 КиБ и tamper rejection.
- Расширены Core, Formats и CLI self-tests, документация безопасности и рабочий процесс.

## 0.7.0

- Добавлен `Iso9660Rebuilder`: безопасная потоковая обратная сборка новой копии ISO без внешних программ.
- Добавлены команды `iso-replace`, `iso-apply-manifest` и alias `iso-patch`.
- Добавлена строгая схема `lucky-star-psp.iso-patch-manifest.v1` с обязательными `schema`/`replacements` и SHA-256/размерными preconditions исходных и новых файлов.
- Файлы манифеста разрешаются только как относительные пути внутри его каталога; абсолютные пути, выход через `..`, symbolic links и reparse points отклоняются.
- Replacement payload размещаются в новых секторно-выровненных extent; существующие данные, каталоги и path tables не перемещаются.
- Обновляются обе endian-копии LBA/длины directory record и числа блоков Primary Volume Descriptor.
- Источник и замены хэшируются повторно во время копирования для обнаружения TOCTOU-изменений.
- Staged ISO побайтно сравнивается с источником вне разрешённых полей, затем полностью разбирается перед атомарным commit; сравниваются SHA-256 целей, число записей и метаданные всех нецелевых путей.
- Замена multi-extent целей, extended attributes, supplementary/partition/unknown descriptors блокируется fail-closed.
- Добавлены лимиты числа замен, размера одной замены, суммарного объёма замен и итогового ISO.
- Добавлены детерминированный Python-oracle patched ISO и независимый валидатор разрешённых метаданных, payload-layout и нулевого padding.
- Добавлены отрицательные тесты неверных схем/хэшей/размеров, дублей, абсолютных путей, неподдерживаемых descriptors и коллизий отчёта.
- Добавлены `rebuild-game-iso.ps1` и `rebuild-game-iso.sh`.

## 0.6.0

- Добавлен самостоятельный потоковый парсер ISO 9660 для образов PSP без внешних программ и runtime-зависимостей.
- Проверяются PVD, дескриптор завершения, дублированные little-/big-endian поля, размер тома, размер логического блока, версия структуры и однодисковый том.
- Добавлены рекурсивный разбор каталогов, регистронезависимый поиск, нормализация версий `;1` и поддержка файлов из нескольких экстентов.
- Добавлены лимиты количества записей и экстентов, глубины каталогов, размера одного каталога и общего объёма каталожных данных.
- Добавлены команды `iso-list`, `iso-extract` и `collect-assets`.
- `collect-assets` создаёт минимальный ZIP с `PARAM.SFO`, `EBOOT.BIN`, `sc.cpk` и `lt.bin`; опционально добавляет `union.cpk`, `pr.bin`, `BOOT.BIN` и `titlein.pmf`.
- Архив ресурсов содержит манифест с SHA-256, фиксированные временные метки и воспроизводимую структуру, но не раскрывает абсолютные локальные пути.
- Добавлена потоковая атомарная запись с откатом исходного файла при ошибке.
- Добавлены скрипты `collect-game-assets.ps1` и `collect-game-assets.sh`, чтобы заказчик мог извлечь только нужные файлы из собственного ISO одной командой.
- Добавлен независимый Python-эталон ISO с обязательными и дополнительными ресурсами и многоэкстентным файлом.
- Добавлены десять независимых отрицательных проверок: endian mismatch, отсутствие terminator, multi-volume, завышенный том, duplicate PVD, неверный block size, interleaving, незавершённый multi-extent, duplicate path и directory cycle.
- Расширены C# self-tests ISO, сборщика ресурсов, детерминированности ZIP, ограничений, CLI и атомарного отката.

- Добавлен независимый Python-oracle для исходного/русского `lt.bin`, BDF и точного RGBA-атласа.
