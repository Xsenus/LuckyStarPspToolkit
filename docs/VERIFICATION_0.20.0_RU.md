# Проверка выпуска 0.20.0

24 сентября 2026 года на Windows с .NET 9 собран production-trusted
`win-x64` релиз. Машинный отчёт `artifacts/releases/0.20.0/build-report.json`
создаётся локально при сборке и не входит в Git.

## Выполнено

- Полный `scripts/build_release.py --rids win-x64 --license-trust <public-trust>`:
  проверка документации, синтетические эталоны и независимые oracles, сборка,
  Core/Formats/Licensing self-tests, интеграция лицензирования, native publish,
  проверка версии и embedded production issuer — успешно.
- На закрытом оригинальном NIM EBOOT отдельный Formats-прогон завершился
  **55/55**. `decrypt-eboot` получил ELF с ожидаемым SHA-256; изменение одного
  байта привело к отказу без выходного файла. Игровой EBOOT не включён в Git.
- Проверены ZIP-целостность клиентского архива, ровно шесть нужных файлов,
  отсутствие игровых ресурсов и известных серверных секретов, версия EXE
  `0.20.0`, production URL и состав клиентского ключа на семь дней.
- HTTPS-страница `https://lspt.blagodaty.online/` ответила `200`.
- Синтаксис девяти `.sh` проверен Git Bash: 9/9. Статическая проверка и
  генератор API-справки прошли; `git diff --check` не выявил ошибок.

## Ограничено или заблокировано

- Полный RGO VWF-патч скрывает японские символы клавиатуры имени в PPSSPP.
  Поэтому запись требует `--experimental-vwf`; клиентская инструкция оставляет
  исходный EBOOT. Исправление MIPS-профиля и повторная игровая проверка нужны.
- Для NIM проверена **расшифровка** EBOOT; профиля его изменения и проверки
  изменённой игры нет. Один крупный ресурс NIM ещё требует классификации.
- Полного перевода и утверждённой карты символов нет. Проверка всего текста
  и всех игровых сцен невозможна без этих материалов.
- Правовой статус унаследованной таблицы RGO VWF описан в
  [уведомлении](../THIRD_PARTY_NOTICES.md); разрешение правообладателя не
  подтверждено.

## Не выполнялось в этой итерации

- Полное прохождение обеих игр и запуск на физической PSP.
- Повторное развёртывание backend или админки: серверный код не менялся.
- GitHub CI для нового коммита: результат появится после публикации.
