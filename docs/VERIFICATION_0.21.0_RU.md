# Проверки 0.21.0 — промежуточный отчёт

Обновлено: 9 октября 2026 года. Клиентский тестовый архив Windows был
подготовлен 5 октября. Полная игровая приёмка не завершена; этот отчёт
не объявляет обе игры полностью проверенными.

## Клиентский комплект и публикация

- Штатная сборка Windows с публичным production-профилем издателя прошла
  25 этапов, все с кодом 0. Самодостаточный клиент 0.21.0 запущен на Windows;
  встроенные issuer и запрет development loopback проверены.
- Минимальный ZIP для тестирования содержит 12 файлов: клиент, инструкции,
  ответы, карта RGO, клиентский ключ и обязательные уведомления о лицензиях.
  Целостность ZIP, перечень файлов, SHA-256 каждого файла и отсутствие
  административных компонентов проверены. Оригинальных игровых ресурсов
  в комплекте нет. Это результат подготовки, а не подтверждение текущего
  местоположения архива на компьютере пользователя.
- На момент передачи сервер подтвердил неактивированный ключ: 7 суток
  от первой активации, одна установка. Этот исторический результат
  не подтверждает состояние ключа после его использования заказчиком.
- CI коммита `62a8f09` отказал из-за несовпадения версии React-панели;
  версия исправлена в `31dddff`. Следующий CI отказал на независимом
  эталоне изображений: байт OS gzip различался между Windows, Linux
  и версиями Python. Эталон теперь явно использует значение 255
  («неизвестная ОС»), не изменяя DEFLATE, распакованные данные или CRC.
  Результат нового GitHub CI нужно оценивать по соответствующему запуску,
  а не по старым успешным проверкам.
- Консольные журналы и результаты сборок не являются частью исходников.
  Пути `artifacts/...` ниже обозначают журналы прежних запусков и могут
  отсутствовать после очистки. Правила: `PROJECT_HYGIENE_RU.md`.
- Повторная проверка 9 октября после нормализации эталона: независимый
  image oracle, статический анализ, актуальность API, XML-документация
  (105 C#-файлов, 0 недокументированных объявлений), сохранённый baseline
  и репозиторный аудит прошли. Тесты форматов с реальными RGO `pr.bin`,
  `union.cpk` и NIM EBOOT: 59 успешно, 0 ошибок. Полный конвейер
  лицензирования в этот день не запускался повторно; его результат выше
  относится к подготовке клиентского комплекта 5 октября.

## Выполнено

- Штатная проверка `python scripts/build_release.py --compile-only`
  завершилась с кодом 0. Журнал запуска:
  `artifacts/build-logs/1dd679f7c17a42bf95f388cff98436a2/` (22 шага, все с кодом 0).
- Тесты ядра прошли; тесты форматов: 56 успешно, 0 ошибок;
  лицензирования: 146 групп успешно. Проверка реального жизненного цикла
  локального сервера, владельца и клиента прошла.
- Независимые эталоны изображений проверяют PNG, фильтры и глубины цвета,
  PSP swizzle, палитры, gzip-кадры, отказ при повреждениях и нехватке места.
- Отдельный запуск тестов форматов с исходными файлами пользователя:
  58 успешно, 0 ошибок, включая NIM EBOOT и RGO `pr.bin`.
- Для исходных шрифтов RGO и NIM экспорт и обратный импорт BDF проверены
  для всех 66 русских букв, без обрезанных пикселей.
- Каталог имён RGO применён к 2922 вхождениям выбранного имени; результат
  проверен повторным разбором собранных сценариев.
- Все десять изображений оригинального RGO `pr.bin` выгружены в PNG.
  Сборка без изменений сохраняет ресурс побайтно. Отдельный тест изменения
  изображения проверяет неизменность остальных пикселей и защищённых байтов.
- Подготовлен приватный тестовый RGO ISO с двумя русскими именами, двумя
  репликами и изменённой надписью атласа. Таблица размеров EBOOT не требует
  изменений; оригинальные EBOOT и шрифт сохранены. ISO собран успешно.
- Оригинальная RGO и тестовый ISO запущены в отдельном PPSSPP 1.20.4;
  идентификатор ULJM05752 подтверждён API. В памяти оригинальной игры найдены
  изображения стартового экрана и заголовка; активный framebuffer ещё не
  подтверждён. Последнее чтение VRAM тестового ISO дало чёрное изображение.
- Для проверки без видимого окна получена [успешная официальная сборка
  PPSSPP Headless](https://github.com/hrydgard/ppsspp/actions/runs/37215121658),
  ветка `master`, commit `51a42daec20d32b3eed9d314ddee9957b3cb38f5`.
  SHA-256 архива проверен по digest GitHub artifact. Инструмент остаётся
  приватным средством проверки и в клиентский пакет не включается.
  API подтвердил оригинальную RGO, выдал снимок настоящего framebuffer
  со вступительным роликом и экраном «Press START» после нажатия Start.
- В тесте отдельно изменённого PR содержимое загруженного в память
  `pr.bin` побайтно совпало с результатом `menu-build`; загруженный шрифт
  совпал с оригиналом. Между контрольным ISO с неизменённым PR и ISO с
  изменённым PR найдено ровно 219 отличающихся байтов, все внутри атласа.
  Этот первоначальный тест давал чёрный экран: `menu-build` не обновлял
  конечную контрольную сумму PR. Независимый пересчёт подтвердил корректность
  суммы оригинала и ошибку изменённого ресурса. После исправления суммы
  PR-only ISO показывает заставку, главное меню, загрузку сохранений и
  рабочую клавиатуру имени в headless PPSSPP. Проверка конкретной изменённой
  надписи ещё не завершена. Также добавлен пересчёт отдельных контрольных
  сумм пяти сжатых атласов; приватные тесты всех пяти правок прошли (58/0).

## Ещё не подтверждено

Совместный ISO с изменёнными SC и исправленным PR прошёл заставку,
главное меню и ввод полного имени до первой игровой сцены. Снимок
реального framebuffer получен без видимого окна PPSSPP. В этой сцене
показана исходная японская реплика: она относится к записи 25328,
а ранний тест менял записи 5 и 6. Поэтому этот запуск подтверждает
работу совместного образа, но не отображение выбранного русского перевода.

- Отображение русских имён, двухстрочной реплики и изменённой надписи
  тестового ISO: требуется просмотр соответствующих игровых экранов.
- Отображение перевода нужных диалогов совместного ISO с изменёнными SC
  и исправленным PR.
- Полный цикл перевода NIM с визуальной проверкой в игре.
- Игра на реальной PSP и длительное прохождение.
- Полная игровая приёмка и публикация версии как завершённого игрового релиза.

## Текущие ограничения

Обработка меню охватывает десять атласов точной исходной RGO
ULJM05752 `pr.bin` и 25 атласов `union.cpk` (2529, 2530, 2531, 2533).
Приватная интеграция union прошла: неизменённые PNG дают побайтно исходный
CPK; правка первого пикселя всех 25 PNG сохраняет размеры и смещения,
палитры и остальные ресурсы; проверки отказа и целостности прошли
(57 тестов, 0 ошибок, `artifacts/union-menu-real-tests.log`). Просмотр
изменённых union-экранов в игре ещё не завершён.
Другие ресурсы, ревизии и меню NIM пока не поддержаны. Экспериментальный VWF-патч с известным дефектом
клавиатуры имени не включён в тестовый ISO. Наличие изображений букв
и успешная сборка ресурса сами по себе не подтверждают игровой результат.

Оригинальные игровые ресурсы, тестовые переводы, ISO и изображения из игры
остаются в приватной рабочей папке и в Git не добавляются.
