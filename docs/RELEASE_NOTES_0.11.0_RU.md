# 0.11.0 — исполняемая проверка и исправление обнаруженных дефектов

## Совместимость

Продолжение реального исходного снимка 0.10.0 (`5d4a4f0`). Целевой framework не изменён:
`net9.0`, C# 13. Публичные команды и формат переводов сохранены. Два дополнительных
параметра `FileLimits` имеют значения по умолчанию, поэтому существующие вызовы совместимы.

## Исправления

* CS9032: четыре internal required-свойства сценарных интервалов; внутренние значения
  теперь имеют явно недопустимое начальное значение -1 и задаются парсером.
* CS0266: четыре элемента кортежей профиля размеров явно имеют тип ushort.
* CS0165: индекс сопоставленного глифа инициализирован до short-circuit выражения.
* CS0103/CS0246: добавлены отсутствующий test-helper и alias типа VWF inspection.
* Неверно присоединённые XML-комментарии передвинуты перед атрибутами. Добавлены
  пропущенные документы к tuple-полю, tuple-key свойству, свойству ISO и enum values.
* Групповая запись больше не откатывает уже зафиксированные файлы из-за ошибки удаления
  второго .bak после успешного удаления первого. Cleanup отделён от commit boundary.
* Временный файл зарегистрирован для cleanup до записи; ошибка записи не оставляет
  незарегистрированный частичный файл. Пути файл/его-потомок отклоняются до staging.
* Демо ожидает код 2 для корректного, но пока неполного русского шрифта.

## Алгоритмы

AES-CMAC: постоянные по размеру сообщения рабочие буферы (два по 64 КиБ, через pool),
проверенная обработка пустого/полного/частичного последнего блока, очистка subkeys
и pooled memory. 81 тег независимо рассчитан Python cryptography. В наблюдаемом
прогоне 4-МиБ сообщения после прогрева — 1392 байта новых managed-выделений;
это не полный RSS и не гарантия на другом runtime.

UTF: `MaximumUtfCells=2_000_000`, `MaximumUtfDecodedBytes=128 MiB`. Каждая копия
постоянного бинарного поля и каждая декодируемая строка учитывается до выделения.
Убран двойной ToArray для binary value. 32-битные некорректные offsets дают
контролируемый код формата вместо OverflowException. 512 заголовочных мутаций:
411 корректно отклонены, остальные структурно допустимы; необработанных ошибок нет.

## Состояние

Реальные C# компиляция/тесты выполнены через локальный Roslyn/PowerShell на .NET 11 preview.
`dotnet build` под .NET 9, self-contained publish, Windows-приёмка, remote CI,
свежий customer EBOOT и PPSSPP НЕ выполнены. Диагностические DLL не распространяются.

## Проверяемая поставка

Упаковщик сохраняет полученную Git-историю вместо создания нового корневого коммита
на каждой версии. Все достижимые исторические деревья проверяются на исключённые
шрифтовые/игровые/бинарные файлы, в том числе удалённые позже. Дополнительно проверяются
fingerprint выполненного C#-прогона и SHA-256 логов; устаревший зелёный отчёт не принимается.
Штатные SDK/Windows/Linux release gates не подменяются Roslyn fallback.
