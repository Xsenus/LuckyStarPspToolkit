# 0.15.0 — надёжность и память сервера лицензирования

Продолжение `v0.14.0`, commit `5a58d7a57b19e77fa05eaefc9c093c036dab612a`.
Сохранены часы/дни/календарные годы/бессрочный доступ, запуск срока от выдачи или активации,
лимит установок, продление, suspend/resume/revoke и строгая онлайн-проверка.

## Исправления

- После скачка UTC вперёд и возврата назад серверная временная шкала больше не замирает:
  опорная точка переустанавливается после каждого наблюдения, доли секунды сохраняются.
- Сервер сохраняет HMAC-защищённый `server-clock.json` перед решением о доступе, включая
  отказ по истечению срока. После перезапуска откат UTC к ранее наблюдённому времени отклоняется.
- Автоматическая миграция базы schema 1 → 2 делает checkpoint обязательным, но не меняет
  издателя, ключи, даты активации, лимиты устройств или сроки выданных лицензий.
- Публичный LicenseStore.Read не раскрывает изменяемые коллекции; результат Change и
  сохранённый callback-снимок также не способны изменить зафиксированное состояние.
- Вместо JSON-клонирования базы используются две явные копии изменяемых коллекций,
  семантическая валидация и одна итоговая сериализация. Внутренние доверенные запросы
  authority используют отдельное чтение без копирования всей базы.
- Отсутствующие обязательные параметры и null для non-nullable полей JSON отклоняются
  до выполнения протокола. Необязательные параметры с defaults остаются совместимыми.
- HTTP 408/429/500/502/503/504 от прокси считаются временными отказами даже без JSON.
  Это не новый допуск и не offline grace: существующая краткая лицензия не продлевается.
- Отказы записи снимка и checkpoint покрыты fault-injection тестами: новое состояние
  не публикуется, подпись допуска не выдаётся при несохранённом времени.

## Проверки

11 сборок реально скомпилированы через Roslyn; 9 групп Core, 53 Formats, 61 Licensing;
1732 именованных C#-объявления, 0 ошибок XML-документации. Процессный тест сервера/администратора/
клиента — 24 шага; синтетическая демонстрация под лицензией — 11 шагов.
Шесть регрессий проверены одинаковым кодом на собранных 0.14.0 и 0.15.0.

На синтетической базе из 2000 лицензий и 1000 установок медиана новых управляемых выделений
за транзакцию уменьшилась с 15 008 792 до 8 641 224 байт (42,43%). Семантический SHA-256
итогового снимка совпал. Это не полный расход RAM и не нагрузочный тест production HTTP/TLS.

**Среда:** .NET 11 Preview через PowerShell/Roslyn, целевая платформа остаётся .NET 9.
Штатный SDK/publish, Windows CNG/ACL, публичный HTTPS, удалённый CI и настоящие игры
не проверены. EXE/DLL, runtime, ключи, файлы игр и шрифтов не включены в исходный комплект.
