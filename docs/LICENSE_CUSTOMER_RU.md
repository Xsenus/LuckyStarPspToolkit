# Активация программы

Распакуйте весь клиентский ZIP в отдельный каталог. Ключ доступа владелец присылает отдельно.
Нужен доступ в Интернет к указанному владельцем серверу лицензий по HTTPS.

```powershell
.\lsptool.exe license activate
```

Вставьте ключ в скрытый ввод и нажмите Enter. Его не нужно помещать в командную строку/историю терминала.
Допустим импорт из полученного файла:

```powershell
.\lsptool.exe license activate --key-file .\access-key.txt
.\lsptool.exe license status
.\lsptool.exe self-test
```

В Linux используйте `./lsptool`. После успешной активации защищённые команды запускаются обычным образом.
`status` проверяется онлайн, а не выводит старое разрешение из кэша. Срок показывается в UTC.
Самодостаточный релиз не требует отдельной установки SDK. Исходный инженерный архив не является таким релизом.

## Что означают ошибки

| Код | Действие |
|---|---|
| LICENSE_NOT_CONFIGURED | Нужна клиентская сборка с издателем от владельца; это не ошибка ключа |
| LICENSE_REQUIRED | Выполните активацию |
| LICENSE_INVALID | Проверьте, что ключ скопирован целиком, и уточните у владельца |
| LICENSE_EXPIRED | Срок закончился; запросите продление |
| LICENSE_SUSPENDED / LICENSE_REVOKED | Доступ приостановлен/отозван владельцем |
| DEVICE_LIMIT | Достигнут лимит установок; владелец может освободить старый слот |
| SERVER_BUSY / RATE_LIMIT | Сервер временно занят; повторите позже. Уже выданный короткий допуск не продлевается |
| SERVER_CLOCK_ROLLBACK / SERVER_CLOCK_INTEGRITY / SERVER_CLOCK_MISSING | Сообщите владельцу: требуется обслуживание времени/данных сервера, а не изменение часов ПК |
| LICENSE_NETWORK | Проверьте сеть, правильное время ОС для TLS и доступность сервера |
| DEVICE_CHANGED / ACTIVATION_INVALID | Изменилась установка ОС/профиль; свяжитесь с владельцем |
| STATE_BUSY | Другая команда программы уже работает в этом профиле пользователя |

Не отключайте TLS и не изменяйте файлы активации. Простая смена календаря на ПК не продлевает срок на сервере.
Бессрочная лицензия также требует онлайн-проверок. При отзыве, истечении краткого допуска или долгом отсутствии
сервера запущенная команда останавливается с кодом 77. Программа не удаляет исходные игровые файлы,
но при принудительном завершении могут остаться временные файлы незаконченной операции.
Не выдавайте незавершённый результат за готовый перевод.

`license device` показывает идентификатор установки для обращения к владельцу.
`license forget` удаляет локальную активацию, но не освобождает серверный слот и не перезапускает пробный период.
В Windows идентификатор связан с текущим пользователем и MachineGuid ОС; в Linux — с локальным ключом и machine-id.
Это лицензирование установки, не учёт физических корпусов компьютеров.

## Какие данные отправляются

Идентификатор продукта, лицензии, открытый ключ установки, его отпечаток и хэш привязки к ОС,
одноразовые запросы и подписи. Сам ключ доступа отправляется при активации по HTTPS.
Содержимое игры, переводы и игровые файлы механизм лицензирования не загружает на сервер.
Сервер/прокси видит сетевой адрес соединения как обычный HTTPS-сервис.
