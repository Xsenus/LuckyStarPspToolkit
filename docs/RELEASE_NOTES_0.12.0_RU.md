# Lucky Star PSP Toolkit 0.12.0 — 22 сентября 2026

Продолжение Git-коммита 1498f04e6d629b2909ddadb4d25e8ef9dd20b27b (0.11.0).

В этой версии переработан сценарный кодек, а не только документация. Исправлены
ложный отказ неизменяющей пересборки при переходах внутрь текста, чтение checksum
как сообщения и переполнение uint32 metadata offsets. Дубли и пересечения выявляются
до чтения строк. Введены бюджеты файла, отдельного поля и всех глифов сценария.

Пересчёт адресов использует проверенный binary-search индекс вместо полного обхода
диапазонов на каждый target. Изменяемыми считаются только реально изменённые
текстовые записи. Итоговый размер проверяется до сериализации, запись выполняется
сразу в один итоговый буфер, без List<byte> и копий каждого raw-диапазона.

Добавлены 13 групп регрессионных C#-тестов, генератор крупных синтетических сценариев,
проверка 16385 targets, 1024 мутации заголовка и сравнение индекса с линейным эталоном.
Новый диагностический benchmark позволяет одним и тем же тестовым кодом измерить
старую и новую сборки, а `--probe` — воспроизвести три исторических дефекта.

Интерфейс CLI и схема JSON перевода совместимы с 0.11.0. Все новые типы, методы,
параметры и возвращаемые значения имеют XML-документацию. Сохраняются единая
сборка `build.cmd`, двухплатформенный CI и draft prerelease по тегу после проверок.

Результаты выполнения и ограничения среды: TEST_REPORT_RU.md. Измерения:
PERFORMANCE_RU.md. Подробности алгоритма: SCRIPT_CODEC_RU.md.

Это инженерная предварительная версия. Нативные Windows/.NET 9, GitHub Actions,
оригинальные sc.cpk/lt.bin/ISO и приёмка игры не подтверждаются альтернативным
Roslyn/.NET 11 прогоном. Ограничение происхождения VWF в THIRD_PARTY_NOTICES.md
сохранено, а не объявлено решённым.
