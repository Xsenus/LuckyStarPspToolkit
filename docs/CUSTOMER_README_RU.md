# Lucky Star PSP Toolkit — клиент

Консольная утилита для извлечения и обратной сборки игровых ресурсов Lucky Star
на PSP. Версия пакета находится в [VERSION](VERSION), результаты его выпуска —
в [BUILD-STATUS.json](BUILD-STATUS.json). Это инструмент для работы с переводом;
оригинальные игровые файлы, готовый перевод и шрифт в пакет не включены.

## Первый запуск

Распакуйте ZIP целиком в отдельную папку. Пакет self-contained: устанавливать
.NET SDK или Python для обычного запуска не требуется. Откройте PowerShell
в этой папке:

```powershell
.\lsptool.exe version
.\lsptool.exe license build-info
.\lsptool.exe license activate
.\lsptool.exe license status
.\lsptool.exe self-test
```

Вставьте отдельно полученный ключ в скрытый ввод активации. Не помещайте его
в командную строку и не публикуйте. В Linux замените `lsptool.exe` на `./lsptool`.
Если `license build-info` сообщает отсутствие издателя, вам выдан заблокированный
preview; получите у владельца настроенный клиентский пакет.

Для обычной работы нужна связь с HTTPS-сервером лицензий. Резерв без связи
работает только после предварительной выдачи владельцем и онлайн-включения
на конкретной установке, не более подписанного срока в 168 часов.

Работайте с копиями разрешённых оригиналов. Сначала выполняйте проверку без
изменений, затем пересборку в отдельный файл. Не используйте синтетическую карту
глифов для настоящей игры. Успешный self-test подтверждает работу тестовых
алгоритмов; готовность вашей игровой сборки проверяется отдельно в эмуляторе/на PSP.
