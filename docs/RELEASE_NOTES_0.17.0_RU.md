# 0.17.0 · резерв, сессии и ограниченные административные операции

Продолжение v0.16.0, без сброса истории и смены issuer. Три воспроизведённых C# дефекта
устранены: недолговечный отказ резерва по сроку, недолговечный отказ по rollback, возврат
исторического grant после reset-device/re-activation.

Добавлена вкладка React «Сессии владельца»: безопасные handle, просмотр возраста/idle,
завершение одной или всех других сессий с CSRF и свежим MFA. Cookie/CSRF других браузеров
в списке не выдаются. Уже допущенные команды не откатываются.

Резерв обновляется без лишней промежуточной ECDSA-подписи. AuditRecent копирует только
500 последних событий. Реальные альтернативные C#-замеры и сырые логи включены.

React: потоковый byte-limit JSON, строгий UTF-8, объединение мелких chunks, immutable
single-flight повторных запросов, canonical property order и изоляция поздних ответов
между сессиями. 8 новых frontend tests; 12 новых C# regression groups.

Обновлять server+web вместе. Клиент обновить отдельно для исправлений локального резерва.
Нет повторного init/web-init, нет смены schema3/ключей. Резерв не вечный master key и не
гарантирует мгновенный отзыв на отключённой машине. Всё ещё source preview: штатные
.NET9/Windows/production HTTPS/PPSSPP не проверены. См. TEST_REPORT_RU.md.
