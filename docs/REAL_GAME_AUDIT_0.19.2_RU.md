# Проверка на двух оригинальных образах — 0.19.2

24 сентября 2026 года пользователь предоставил закрытый ZIP с двумя вложенными
7z-архивами, содержащими полные ISO Ryouou Gakuen Outousai Portable (RGO) и
Net Idol Meister (NIM). Игровые файлы и текст из них не добавлены в Git,
публичный релиз или клиентский пакет. Проверки выполнялись на отдельной копии.

| Проверка | RGO | NIM |
|---|---:|---:|
| `PARAM.SFO` / DISC_ID | ULJM05752 | ULJM05542 |
| ISO 9660, PSP UMD file-structure version 2 | 36 записей | 36 записей |
| Извлечение `sc.cpk`, сравнение с независимым распаковщиком | совпало по SHA-256 | совпало по SHA-256 |
| `collect-assets`, 4 обязательных файла | полный комплект | полный комплект |
| Побайтовый no-change `cpk-verify` | 12 записей, PASS | 596 записей, PASS |
| Разбор сценарных записей | 12/12 | 595/596 |
| Обратная сборка отдельного ISO с исходным `sc.cpk` | PASS | PASS |
| Исполняемый файл | точная проверенная ревизия | PRX tag `0xD9160BF0` не поддержан |

Запись 595 в NIM имеет размер 167936 байт и не проходит сценарный parser:
таблица диалогов не помещается в метаданные. Начало файла похоже на массив
смещений. Этот файл нельзя автоматически объявлять сценарием; его назначение
нужно исследовать отдельно. Остальные 595 записей прошли проверку контрольной
суммы и структуры сценария; подсчитано 24628 диалогов и 1567 вариантов ответа.
В RGO подсчитано 27306 диалогов и 892 варианта ответа.

Реальные ISO выявили два дефекта версии 0.19.1: ISO-парсер принимал только
стандартное значение версии структуры `1`, хотя оба PSP-образа используют `2`,
а `inspect` для каталога падал при сериализации игнорируемого бинарного поля.
В 0.19.2 значение `2` допускается только при системном и прикладном
идентификаторах `PSP GAME`; остальные значения и чужие образы отвергаются.
Добавлены синтетические регрессионные проверки обоих исправлений. Команда
`inspect` не предназначена для чтения гигабайтного ISO целиком: сначала
используйте `iso-list`, затем `iso-extract` и `sfo` для `PARAM.SFO`.

Полный локальный конвейер 0.19.2 завершился успешно: сборка, Core, Formats,
Licensing, интеграция доступа и native self-contained Windows publish. Выпущенный
EXE с production public trust отдельно открыл ISO обеих игр и проверил NIM CPK.
Отчёт сборки фиксирует `compiled: true`, `testsPassed: true`,
`nativeSmokePassed: true` и `gameRuntimeVerified: false`.

У заказчика пока нет готового полного перевода. После основной проверки найдена
открытая таблица символов RGO в [RyououGakuenToolkit](https://github.com/TimepieceMaster/RyououGakuenToolkit).
Её 3543 записи совпали с числом глифов исходного `lt.bin`. На реальных файлах
проверены экспорт и импорт двух реплик сценария 0, создание шрифта с 66
русскими буквами, пересборка `sc.cpk`, VWF-патч EBOOT и отдельный ISO. Хэши
трёх замен внутри ISO совпали с подготовленными файлами. Игровые ресурсы и
пробный ISO хранятся только в закрытой локальной папке, не в Git.

Визуальное отображение и прохождение до этих реплик в PPSSPP/PSP, переходы
сцен и save/load остаются непроверенными. Изменённый EBOOT второй игры тоже
не проверен. Бинарная проверка сборки не завершает игровую приёмку требований
о корректном чтении перевода обеими играми.
