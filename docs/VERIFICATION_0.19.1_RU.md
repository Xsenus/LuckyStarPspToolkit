## Работа установленной админки

Админка и клиентский API доступны на [https://lspt.blagodaty.online](https://lspt.blagodaty.online).
На момент проверки сертификат домена действителен, срок окончания — **21.12.2026**;
проверка TLS не отключалась. Production-проверка web/API прошла **12/12**:

- главная страница и `/health` возвращают 200;
- закрытый bearer-admin маршрут `/admin/licenses` через публичный origin даёт 404;
- анонимная сессия получает 401, запросы без допустимого Origin/CSRF — 403;
- вход владельца, защищённый список, выдача ключа и выход проходят;
- после выхода прежняя сессия возвращает 401.

Дополнительно выполнена визуальная проверка страницы входа в настоящем браузере
через production HTTPS. Проверены защитные cookie attributes и CSP.
Тест продления сертификата в staging (`dry-run`) прошёл. Ответы ранее работающих
сайтов сохранили прежние хэши после установки; соседние сервисы не заменялись.
Порядок обслуживания и обновления: [руководство VPS](VPS_DEPLOYMENT_RU.md).

Эта production-проверка отличается от 32-шагового локального Chromium-сценария:
у последнего `productionHttpsTested: false`, и его результат сам по себе не
подтверждает сертификат или настройки реального VPS.

## Выпущенный Windows-клиент и перезапуск

Проверен именно опубликованный self-contained EXE с production trust profile,
а не диагностическая DLL. `version` и `license build-info` показали ожидаемую
версию/издателя; рабочая команда до активации завершилась кодом 77. Активация
через HTTPS завершилась кодом 0, `license status` показал active, нативный
`self-test` завершился кодом 0. Полный licensed synthetic demo также прошёл
с проверяемым встроенным отчётом; это по-прежнему синтетические игровые данные.

После перезапуска authority прошли 11 web/API проверок; ранее выданная лицензия
сохранилась. Затем проверены отзыв через HTTPS и фактический отказ этого же EXE
с кодом 77. Успешный старый lease не был принят за бессрочное разрешение.
Для теста использовалась отдельная лицензия; её ключ в документацию не включён.

Сделана согласованная резервная копия при остановленной службе; после запуска
health снова прошёл, служба включена в автозапуск, `NRestarts=0`. Базу и пароли
нужно хранить закрыто, вне Git и клиентских пакетов. Проверка создания backup
не является отдельной проверкой восстановления полной копии на другом сервере.
