## Повторная проверка перед push

Из корня репозитория:

```powershell
python validation/audit_repository.py
git diff --check
git status --short
git diff --cached --stat
```

`audit_repository.py` проверяет tracked-файлы текущего дерева. До первого
добавления нового файла проверьте его содержимое и путь; после `git add`
повторите аудит. Не добавляйте рабочие каталоги issuer/owner, enrollment,
recovery-коды, дампы серверной базы, приватные материалы заказчика и архивы
полного owner-комплекта. Новый imported bundle/history требует отдельного
повторения проверки всех коммитов, а не только текущих tracked-файлов.
