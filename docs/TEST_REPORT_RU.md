# Фактическая проверка 0.13.0

## Исходная база

Продолжен Git-коммит `0f5fb516c5dbb9e8e8eff2fa325b4bf08fe2aa1f`, тег `v0.12.0`.
Архив 0.12.0 проверен по SHA-256
`dc12c55ee1dc92b4ef4a712ebfaa6955657349b611c349157542be57ceb8e3d6`.
Все 252 исходных Git-файла совпали с `project/` базового архива.
Базовый C# код заново скомпилирован и его 9 + 42 группы тестов и 11 шагов демо
прошли ДО изменений. Эти материалы отдельно помечены `reports/baseline-0.12.0/`.

## Компиляция и выполнение новой версии

Фактически выполнены шесть компиляций Roslyn/C#13 с Release-оптимизацией:
Core, Formats, CLI, Core SelfTests, Formats SelfTests, Documentation.
Среда: PowerShell 7.7.0-preview.4, .NET 11.0.0-preview.6.26359.118,
reference System.Runtime 11.0.0.0. Это **не** SDK/MSBuild .NET 9 и не запуск
native Windows EXE. Результаты этих разных видов проверки не объединяются.

Основные сборки и тестовые проекты в этом прогоне не выдали предупреждений
компилятора. Documentation выдаёт CS1701 согласования reference assemblies
Roslyn (10) и host (11); все 240 предупреждений сохранены в журнале, а не скрыты.
Ошибок компиляции нет. Чужие compiler/runtime и наши диагностические DLL
в исходный комплект не включены.

## Подтверждённые дефекты прежней версии

Одинаковый `CpkScaleFixture.cs` скомпилирован отдельно против реально полученных
старой и новой Formats DLL, затем выполнен в отдельных процессах:

| Проверка | 0.12.0 | 0.13.0 |
|---|---|---|
| No-op с nonzero padding/trailer | Байты меняются | Точная независимая копия |
| Unknown Tag/Blob при DataL → DataH | Подмена Tag, потеря Blob | Оба значения сохранены |
| UInt64.MaxValue в ItocOffset | OverflowException | ToolkitException:CPK_ITOC_OFFSET |
| Header Files=999 при двух записях | Принят | ToolkitException:CPK_FILE_COUNT |

Также проверены обратная миграция, переставленные столбцы, shared constants,
отсутствующее поле назначения (явный отказ), чужие дополнительные индексы,
нулевые/некорректные размеры, несуществующий ID и прямые изменения mutable-entry.

## Общий протокол

**30 групп пройдено, 0 ошибок, 9 проверок не выполнены.**
`reports/validation-summary.json` хранит реальный код завершения, логи и fingerprint
исходников/сборочных настроек/генераторов. `reports/managed-fallback/` содержит
вывод настоящих компиляций и исполнения C#. Хэши проверяют целостность отчётов,
но не являются цифровой подписью или аттестацией удалённого CI.

Проверки архивов и повторного выполнения после распаковки записываются отдельно
в `reports/clean-source/` полного комплекта. Они относятся к тому же Git-дереву;
упаковочные тексты и отчёты не являются исполняемой программой.

## Не выполнено

Штатные .NET 9 restore/build/self-tests/Roslyn-audit/publish, native Windows,
задания GitHub Actions и запуск переведённой игры в PPSSPP/PSP не выполнены.
Настоящие `archive.zip`, `sc.cpk`, `lt.bin` и чистый ISO здесь отсутствуют.
Согласованность сохранённого customer baseline проверена, но не выдаётся за
повторную обработку исходных EBOOT-байтов или игровых ресурсов.

Новый CPK-код не является универсальным потоковым CRI-инструментом: CLI всё ещё
читает CPK в ограниченный byte[], дополнительные индексы отклоняются, нового
CRILAYLA-компрессора нет. Смотрите `CPK_CODEC_RU.md` и `THIRD_PARTY_NOTICES.md`.
