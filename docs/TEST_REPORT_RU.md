## 25 новых C#-групп

Детерминированный тестовый барьер оборачивает РЕАЛЬНЫЙ 600000-итерационный PBKDF2,
а не подменяет результат успешным паролем. Пока один поток остановлен на барьере,
другой должен завершить Require/List/Logout и независимое повторное MFA.
Проверяются отсутствие очереди login/reauth; отзыв/выход/idle и absolute expiry;
один recovery/TOTP в двух полосах; отмена до начала и до фиксации; ошибка verifier,
ошибка диска; shutdown; null/CSRF; независимые бюджеты; привязка reauth к сессии;
истечение TOTP во время проверки; строгая граница 300 секунд. Код, который не был
израсходован до отказа/отмены, сохраняется. Поздний ответ не восстанавливает сессию.

HTTP-группа без browser bridge держит два незавершённых `/api/login` тела. Третий
получает 503 с Retry-After и no-store, но чтение сессии и reauth выполняются.
Анонимные POST и неверный CSRF отклоняются ДО чтения всего тела. Загрузка, завершённая
после logout, повторно проверяется и отвергается. Тест использует только временный
loopback-сервер. Проверка его HTTPS на реальном домене этим не выполнена.

## Nginx — воспроизведено отдельно

Старый шаблон имел один ingress-бюджет для login и reauth. При 9 последовательных
запросах перегружается выбранный маршрут (429). Следующий запрос к другому маршруту
в .18 также возвращает 429, в .19 — 200. Обратная последовательность проверена на новом
изолированном экземпляре. Обычное чтение в обоих случаях остаётся 200.

Nginx запускается с временным prefix/config, порты только loopback. Сертификат создаётся
на время теста, HTTPS-клиент проверяет сертификат и IP; проверка TLS не отключается.
Upstream — явно синтетический echo без аутентификации. Это изоляция proxy-лимитов,
а не сквозная production-проверка TLS и C#-сервера. Системная конфигурация Nginx не меняется.
Сырые наблюдения: `reports/admin-proxy/`. Временные приватные ключи удалены, в ZIP их нет.

## Frontend и браузер

8 новых Node-тестов проверяют сообщения занятости, отдельные лимиты, generic MFA failure,
просроченную сессию/остановку, recent-MFA и отсутствие подтверждённого ответа. Пароли/коды
не переотправляются автоматически; неизвестный exception не отражается в форме.
Прежние 28 тестов пагинации/повтора запросов/потокового JSON продолжают проходить.

Нативная навигация Chromium была предпринята и заблокирована политикой среды:
ERR_BLOCKED_BY_ADMINISTRATOR. Политика не менялась; попытка не считается PASS.
Затем настоящий React отрисован, API передан диагностическим HTTP-мостом настоящему
backend. Эти 32 шага не проверяют нативное enforcement браузерных cookie/CSP, TLS
на реальном домене и native downloads. Реальная loopback HTTP-проверка C# и отдельный
Nginx TLS-тест также не заменяют эти отсутствующие браузерные гарантии.
