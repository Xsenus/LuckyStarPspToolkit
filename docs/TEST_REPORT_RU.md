## Реально выполненные проверки

Python syntax; Bash syntax для 9 скриптов; комментарии методов, XML и членов моделей; актуальность API reference; генерация независимых CPK/script/CRILAYLA/LT/BDF/ISO эталонов; статические контракты проекта; аудит исходников на известные customer hashes и типовые секреты; согласованность сохранённых customer-отчётов с профилями; независимые проверки шрифта, ISO, обратной сборки ISO; Python регрессии release tooling; Git whitespace.

Проверка ISO включает 10 отрицательных вариантов и сверку точного SHA-256 перестроенного синтетического образа. Проверка LT/BDF проверяет 66 тестовых русских глифов и сохранение служебных данных; она исполняет Python-реализацию, а не C#.

В 17 Python-тестов входят реальные неуспешный/успешный дочерние процессы, запуск driver с пустым PATH, отказ без SDK, сохранение старого релиза при ошибке, injected-ошибка второго rename и откат, стабильный ZIP, права executable для Linux и .sh, отклонение ссылок/опасных имён/шрифтов/бинарников в source handoff. Сценарий падения компилятора явно **моделируется** для проверки логики driver и НЕ считается запуском компилятора.

## Исправления

- Публикация RID теперь выполняет собственный restore, вместо ошибочного reuse нейтрального restore с `--no-restore`.
- Ненулевой native exit не теряется в многострочных PowerShell шагах; один общий driver используется на обеих платформах.
- Новый пакет не объявляется готовым после ошибки или только по наличию файла; отсутствующий SDK возвращает exit 2.
- CLI negative demo ожидает правильный exit 3, а не код неполного набора ресурсов 2.
- `gh release` получает явно заданный repository; создаётся draft prerelease, не stable-релиз без приёмки.
- Исправлен неконструируемый target `IReadOnlySet<ushort>` для collection expressions; используется `ReadOnlySpan<ushort>`.
- Отклоняются повторяющиеся/экранированные JSON-ключи; JSON ограничен текстовым лимитом.
- CPK и план нельзя записать поверх файлов внутри workspace.
- Исправлена проверка пути от `/` или корня диска; Windows-style traversal отвергается также на Unix.
- Карта глифов хэшируется, разбирается и копируется из одного снимка. Убрана лишняя сортировка trie.
- Введены лимиты decoded glyph text / длины одной метки до Split и создания trie; из JSON-чтения убрано ненужное выделение полной строки ради проверки UTF-8.
- Повторная локальная сборка не отвергается только из-за игнорируемых bin/obj; source ZIP можно проверить до git init.
- Новый snapshot bundle не содержит исторические бинарные/шрифтовые blobs. Полная старая Git-история не выдаётся за очищенную.

## Ограничения

Нет измерений производительности на настоящем sc.cpk, подтверждённого полного round-trip этой игры и видео запуска. Исходный VWF-профиль требует отдельного provenance/rights review; прежняя безусловная clean-room гарантия снята. .NET self-contained пакеты и remote CI остаются неподтверждёнными до фактического успешного выполнения.

Исходный development commit новой версии и source hashes записываются в MANIFEST.json внешнего handoff после commit. Точные команды, exit codes и логи — в reports/validation-summary.json и соседних логах полного архива. Для повторения: `python scripts/release_validate.py` (exit 2 при частичной проверке) и `build.cmd --rids win-x64` в реальной .NET-среде.
