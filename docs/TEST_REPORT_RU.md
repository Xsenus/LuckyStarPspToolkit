## Воспроизведение

При установленном .NET 9 SDK основная обязательная проверка:

```powershell
.\build.cmd --rids win-x64
```

Диагностический fallback для разработчика, у которого уже есть подходящий доверенный
PowerShell с Roslyn и `ref`-сборками (ничего не загружает):

```powershell
python scripts/verify_roslyn.py --pwsh <полный-путь-к-pwsh>
```

Fallback не создаёт принимаемый бинарный релиз. Его результаты пишутся отдельно в
`artifacts/validation/managed-fallback/`. Эти логи и source hashes перенесены в
`reports/` полного комплекта. Каждая стадия имеет реальный код завершения.

## Не выполнено

* Штатные restore/build/test/publish .NET 9 и SDK analyzers.
* Нативный запуск Windows EXE и задания GitHub Actions.
* Свежая обработка оригинального archive.zip/EBOOT: входных bytes здесь нет.
* Настоящие sc.cpk, lt.bin, ISO, рендеринг и игровой процесс в PPSSPP/PSP.

Сохранённые хэши старой ревизии не считаются новым прогоном на файлах заказчика.
Полный проект нельзя называть принятым русификатором до этой проверки.
