# Состав проекта и временные файлы

В основной ветке хранятся исходники, тесты, синтетические эталоны, схемы,
профили форматов, сценарии сборки, документация и компактные исторические
отчёты. Это необходимые материалы проекта, а не клиентский комплект.

Оригинальные игры, ISO, игровые ресурсы, приватные переводы, ключи клиентов,
пароли, база лицензий и рабочие ключи подписи в Git не входят. Рабочие
секреты владельца нельзя удалять как кеш: без них теряется доступ к серверу
и возможность обслуживать выпущенные лицензии.

Каталоги `artifacts`, `bin`, `obj`, `__pycache__`, `node_modules`, `dist`,
`TestResults`, журналы `.log`, временные `.tmp`, резервные `.bak` и файлы
редактора `.swp` не публикуются. Старые консольные журналы удалены из текущего
Git-дерева; результаты прежних проверок сохранены в отчётах и истории Git.

Сборка и тесты вновь создают временные файлы. После проверки их можно убрать;
`git status --short` проверяет изменения исходников, а
`git ls-files --others --ignored --exclude-standard` показывает оставшиеся
локальные файлы, исключённые из публикации. Игнорируемый файл не обязательно
является мусором: перед удалением проверьте, не содержит ли он оригинальные
данные или рабочие секреты. Не используйте безусловный `git clean -xfd`.

Инструкция восстановления среды находится в `BUILD_AND_RELEASE_RU.md`.
Тестовые бинарные эталоны создаются командой
`python scripts/reference_oracle.py`; изображения проверяются отдельным
`python validation/validate_image_fixtures.py`. Проект не требует хранения
локальных сборок, скачанных эмуляторов или копий исходников в соседних папках.

Чистота каталога и успешная компиляция не подтверждают игровую приёмку.
Фактические выполненные и незавершённые проверки — в
`VERIFICATION_0.21.0_RU.md`.
