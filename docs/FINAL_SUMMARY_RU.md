# Поставка владельцу 0.16.0

Реализованы React-админка, пароль/TOTP/recovery, отдельный browser backend и подписанный резерв до168ч.
Основа: 0.15.0 с сохранением истории Git. Все новые C# методы/типы имеют XML summaries; frontend — JSDoc.
Полный ZIP только для владельца. Заказчику: отдельно опубликованный клиент и access-key.txt.

Начать: ADMIN_WEB_RU.md (сборка/HTTPS/VPS/MFA), RESERVE_ACCESS_RU.md (режимы/выключение/границы).
Внешний master bypass отсутствует. Для полного функционального доступа с периодическим контактом
выдаётся бессрочная обычная лицензия + reserve grant на168ч конкретной активированной установке.
При отсутствии обновления7дней программа блокирует команды; отключённый от сети клиент не узнаёт
об отзыве мгновенно, максимум задержки равен оставшемуся подписанному сроку.

В owner-web/ готовые статические ресурсы React. C# runtime binaries/Windows EXE здесь не поставляются:
реальная компиляция/тесты выполнены на Roslyn/.NET11 Preview, а native .NET9 publish ещё обязателен.
