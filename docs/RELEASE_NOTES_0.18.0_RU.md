# Версия 0.18.0 — серверная пагинация React-админки

Последовательное продолжение v0.17.0 (fbf27fd92f4817e756266916161feb8525b95f20).
Нет изменений сроков/активаций, issuer или ключей. Клиентский протокол совместим.

- Лицензии и резервы: bounded server pages, stable ordering, literal filters и counters.
- Установки: только подробная карточка выбранной лицензии; публичные ключи не включены в список.
- HMAC-курсоры с привязкой к фильтрам/размеру/endpoint/ревизии и исходным 120 секундам.
- React показывает устаревание страниц и обновляет первую; late responses не затирают результат.
- Устранено ограничение UI на первые 200 резервов; проверена история из 231 записи.
- Статус резерва учитывает родительскую лицензию и установку, но не выдаётся за онлайн-телеметрию.
- Policy update возвращает только маленький ответ; прежний private API совместим.
- Все *.test.mjs запускаются через общий Node runner, без shell glob и забытых файлов.
- 12 новых C# групп и 10 Node tests. Демо проверяет страницы настоящего backend.

Сравнение на 2000 лицензий/4000 установок: UTF-8 JSON 1684891 -> 5016 байт;
медиана allocatedBytes за 20 чтений 53398400 -> 273280. Видимые 25 UUID равны эталону.
Нет заявлений о полном RSS или production HTTPS throughput.

Обновить server/admin/owner-web одновременно; не выполнять init заново. Миграции схемы
нет. Старый клиент продолжает работать. После перезапуска повторно войти в админку.
Нативная .NET9/Windows/HTTPS и настоящая PSP-проверка не выполнены; см. TEST_REPORT_RU.md.
