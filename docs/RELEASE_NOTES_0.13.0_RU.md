# Lucky Star PSP Toolkit 0.13.0 — 22 сентября 2026

## Содержательные изменения

* Общий `CriCpkLayout` проверяет метаданные и диапазоны всех файлов без копирования
  CPK целиком или его вложенных ресурсов. Его используют Parse, Inspect, Extract
  и проверка результата Build: правила разбора не расходятся между командами.
* Публичные `CriCpkArchive.Inspect` и `Extract` дают каталог и один выбранный ресурс
  без материализации остальных файлов. CLI `cpk-list` и `cpk-extract` используют их.
  Сам входной CPK в CLI по-прежнему читается в один ограниченный byte[] — это не
  полностью потоковая реализация и не поддержка CPK > Int32.MaxValue.
* No-op Build возвращает отдельную побайтно идентичную копию исходника, включая
  неизвестный prefix, межфайловый padding и trailer. Повторная установка тех же
  байтов или отмена правки также дают точный no-op. Изменённая сборка по-прежнему
  нормализует layout и может убрать padding/trailer; нет обещания совпадения всего
  изменённого контейнера побайтно с оригиналом.
* При переходе DataL ↔ DataH дополнительные поля сопоставляются по имени и точному
  типу. Binary/string/числовые значения сохраняются. Различающиеся shared constants
  переводятся в per-row. Несовместимая схема даёт CPK_METADATA_SCHEMA вместо потери
  или выдумывания неизвестного значения. Карта полей вычисляется один раз на схему.
* Build проверяет итоговые диапазоны и сравнивает spans; больше не создаётся вторая
  полная копия CPK и всех его файлов исключительно ради повторной проверки.
* До крупных копий проверяются входной лимит и общий бюджет metadata-пакетов
  `MaximumCpkMetadataBytes` (32 МиБ по умолчанию). Существующие UTF decoded/cell
  лимиты продолжают действовать. Это бюджет байтов пакетов, не общий RSS процесса.
* UInt64 offsets/lengths проверяются до преобразования; повреждение возвращает
  ToolkitException с кодом формата, не случайный OverflowException. Header Files
  обязан совпадать с ITOC. Дополнительные активные TOC/ETOC/GTOC индексы явно
  отклоняются: переразметить их этот ITOC-only сборщик пока не умеет.

## Проверки

Добавлены 11 групп C# регрессий: exact no-op/ownership, двусторонняя миграция,
несовместимые поля, бюджеты и UInt64, дополнительные индексы, ошибки дескрипторов,
metadata-only API, прямые мутации, границы 65535/65536, 512 header mutations,
масштабирование выделений памяти. Все они реально выполнены вместе с прежними тестами.

Компиляция и выполнение — Roslyn/C#13, Release, PowerShell 7.7.0-preview.4,
.NET 11.0.0-preview.6.26359.118. Это не MSBuild/.NET 9 SDK и не native Windows.
GitHub Actions и целевые self-contained пакеты здесь не запускались/не выпускались.
Настоящие archive.zip/sc.cpk/lt.bin/ISO отсутствуют; старые отчёты не считаются
новым raw-byte прогоном и не подтверждают игровую приёмку.

Сравнение памяти и воспроизводимых дефектов: `CPK_PERFORMANCE_RU.md`.
Как использовать и показать: `USAGE_RU.md`, `CUSTOMER_DEMO_RU.md`.
