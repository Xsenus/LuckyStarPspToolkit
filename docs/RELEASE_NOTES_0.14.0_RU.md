# 0.14.0 — серверное лицензирование

Продолжение реального коммита 0.13.0 `5f2f6323318c5817265c22d72c88906203a68c54`, без сброса истории.
Добавлены пять проектов: Licensing, Licensing.Authority, LicenseServer, LicenseAdmin и Licensing.SelfTests.
Основные алгоритмы CPK/сценариев/шрифтов/ISO сохранены; CLI теперь проходит лицензионный шлюз.

Реализованы часы/сутки/календарные годы/бессрочно, старт с выдачи или активации, лимит установок,
одноразовые possession proofs, короткие подписанные разрешения, watchdog, suspend/resume/revoke/extend/permanent/reset,
идемпотентность выдачи/изменений, HMAC-снимки базы, эксклюзивный писатель и атомарная инициализация издателя.
Приватный подписант не входит в клиентский пакет. Клиентские сборки без public trust заблокированы.

Оптимизации: индекс ключей, readonly heartbeat без переписывания базы, bounded expiry queue для nonce,
переиспользование HttpClient, отдельные ресурсы управления при нагрузке на публичный порт.

Обновлены native build/release pipeline и диагностическая Roslyn-проверка; тестовый издатель создаётся отдельно
и удаляется после сквозного сценария. Production release требует публичную переменную LSP_LICENSE_TRUST_JSON;
CI без неё публикует только LOCKED preview. Owner tools выпускаются отдельным owner-only ZIP.

Шаблоны Nginx/systemd и инструкции подготовлены, но не являются отчётом настройки VPS.
Целевая платформа остаётся .NET 9. Диагностический .NET 11 preview не заменяет штатный publish/Windows CNG.
Новых реальных игровых файлов не поступало; игровая приёмка и происхождение VWF остаются отдельными вопросами.
