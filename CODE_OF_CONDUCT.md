# Code of Conduct

## Our standard

Project participants are expected to be respectful, technically honest, and constructive. Helpful behavior includes:

- discussing code and evidence rather than attacking people;
- reporting uncertainty and skipped tests explicitly;
- welcoming questions from translators, reverse engineers, and first-time contributors;
- respecting copyright, licenses, privacy, and ownership of game files;
- accepting maintainers' requests for reproducible tests and safer failure behavior.

Unacceptable behavior includes harassment, discrimination, threats, publication of private data, deliberate misrepresentation of test results, or distributing copyrighted game/firmware assets through project channels.

## Enforcement

Report conduct concerns privately through the security/contact mechanism documented in `SECURITY.md`. Maintainers may edit or remove contributions, restrict participation, or take other proportionate action to protect contributors and the project.

## Scope

This code applies in repository discussions, issue trackers, pull requests, release channels, and other spaces where a participant represents the project.
